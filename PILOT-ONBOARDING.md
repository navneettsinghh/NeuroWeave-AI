# CONVERTIQ Pilot Onboarding Checklist

Use this checklist before configuring a first paid pilot. Do not add secrets to the repository; provider credentials belong in the approved deployment environment only.

## Business

- [ ] Business name
- [ ] Business type
- [ ] Service areas / locations
- [ ] Working hours
- [ ] Services / property types
- [ ] Public contact phone
- [ ] Public contact email

## Lead Sources

- [ ] Website enquiry form
- [ ] Existing forms
- [ ] Advertising sources
- [ ] WhatsApp entry points
- [ ] Social channels
- [ ] Confirm consent/compliance expectations for each source

## Qualification

- [ ] Qualification questions
- [ ] HOT rules
- [ ] WARM rules
- [ ] COLD rules
- [ ] Escalation rules
- [ ] Required fields before agent handoff

## Messaging

- [ ] Welcome message
- [ ] Qualification messages
- [ ] Follow-up messages
- [ ] Human takeover rules
- [ ] Tone and language preferences
- [ ] Approved template requirements, if using a WhatsApp Business/API provider

## Team

- [ ] Agent names
- [ ] Assignment rules
- [ ] Notification destination
- [ ] Manager / owner escalation path
- [ ] Human takeover owner

## Testing

- [ ] Test lead capture
- [ ] Test conversation
- [ ] Test notification
- [ ] Test human takeover
- [ ] Test appointment status
- [ ] Test duplicate lead handling
- [ ] Test provider failure fallback

## Launch

- [ ] Provider credentials configured outside the repo
- [ ] Approved WhatsApp templates reviewed
- [ ] Consent/compliance review complete
- [ ] Client approval received
- [ ] First-week review meeting scheduled
